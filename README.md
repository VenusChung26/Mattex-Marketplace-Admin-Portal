# Mattex Marketplace Admin Portal

Sales portal for RFQs, products, and buyer accounts.

- Local: `npm install` then `cp .env.example .env.local` (fill keys) then `npm run dev` → http://localhost:5181
- Data: same Mattex Supabase as Marketplace (`https://pgzdcrlrxukvblydknkn.supabase.co`)
- Marketplace storefront stays in [VenusChung26/Subbie](https://github.com/VenusChung26/Subbie)

Do not commit `.env.local`.
