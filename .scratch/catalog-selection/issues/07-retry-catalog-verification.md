# 07: 核對失敗保留草稿並重試

**What to build:** 提交前若無法取得最新商品資料，買家收到清楚提示，既有選擇與其他填寫資料完整保留；恢復連線後可重試核對，通過才建立詢價或採購單。

**Blocked by:** 05：失效規格必須重選。

**Status:** done

- [x] 最新商品資料讀取失敗、逾時或無法確認時，標示「尚未核對」並暫停提交，不將未知狀態當作有效選擇。
- [x] 核對未通過時，不建立新詢價／採購單，也不發出提交成功的通知或清空草稿。
- [x] 尺寸、規格、各行數量、聯絡、交付及既有訂製資料在失敗後繼續保留。
- [x] 買家可主動重試；恢復連線後重新取得最新資料並核對，不直接沿用先前未知的結果。
- [x] 重試後發現規格失效或數量不足，分別引導重選或確認增購；全部有效才可提交。
- [x] 詢價與即買入口均遵守同一核對規則，過程中不自行重複送出建立記錄的動作。
- [x] 以可控制的讀取失敗及恢復情境，驗證保留資料、暫停建立記錄、重試及成功提交的完整路徑。
