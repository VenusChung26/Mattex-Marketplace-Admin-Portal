# 01: 買家商品目錄前後一致

**What to build:** 買家第一次開頁與後續載入時，看到同一份商品、分類及尺寸／規格選項。將現有買家商品整理規則集中，讓伺服器首次呈現與瀏覽器更新共用結果，沿用目前買家頁的選購方式。

**Blocked by:** None (can start immediately).

**Status:** done

- [x] 同一份來源商品資料，首次開頁與後續載入的商品集合、分類、規格合併及選項次序一致。
- [x] 沿用目前買家頁的分類、尺寸／規格合併、價格顯示及上下架規則，不重新設計選購方式。
- [x] 買家版本繼續排除內部資料；後台仍可取得處理商品所需的完整資料。
- [x] 商品內容更新後，買家目錄及版本識別一致更新；未變動時仍可沿用現有快取，不造成錯誤的更新提示。
- [x] 商品讀取的現有備援來源仍可使用，且經相同買家整理規則處理。
- [x] 以具代表性的合併商品、下架商品及分類資料，回歸驗證兩條呈現路徑輸出一致；用瀏覽器核對首次呈現與更新後畫面。
