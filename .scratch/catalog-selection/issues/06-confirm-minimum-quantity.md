# 06: 最低購買量提高須確認增購

**What to build:** 買家已選數量在商品更新後低於最低購買量時，仍看見自己原本的需求與不足原因；由買家確認調整數量後才可提交，不擅自增加詢價或採購量。

**Blocked by:** 02：商品選擇完整保留到草稿。

**Status:** done

- [x] 原選 10件、最低購買量更新為 20件時，商品畫面及草稿仍保留 10件，並顯示需要調整的提示。
- [x] 不因刷新、重新計算規格或切換展示位置，自動將既有選擇改為 20件。
- [x] 最低購買量按實際商品選擇判定，不以同款其他規格的數量或兩行合計替代。
- [x] 買家明確調整至合規數量後，畫面、草稿、提交明細及文件的數量一致；未確認前暫停該選擇的提交。
- [x] 詢價及即買採購單的最終提交均處理數量不足，伺服器亦拒絕不合規的標準商品選擇。
- [x] 首次選購的合理預設及完整訂製需求流程保持可用，不將更新後增購當成已獲買家確認。
- [x] 回歸驗證最低購買量上升、原數量已足夠、買家調整，以及同款不同規格各自判定的情境。

## Comments
