# 02: 商品選擇完整保留到草稿

**What to build:** 買家在商品卡、列表或詳情頁選定尺寸、規格及數量後，有效選擇經商品刷新、加入草稿、登入及草稿還原仍保持一致。先作相容擴充，為之後按商品選擇分行建立共用依據，保留舊草稿可讀性。

**Blocked by:** None (can start immediately).

**Status:** done

- [x] 商品卡、列表及詳情頁對同一商品選擇，採用一致的尺寸、規格、數量及選擇後商品資料。
- [x] 同一商品刷新且選項仍有效時，保留買家的選擇與數量，不因重新載入商品資料而重設。
- [x] 加入草稿後，登入前的待處理選擇、登入後還原及重新開啟草稿均保留原選擇。
- [x] 新表示方法能區分同款商品的不同尺寸／規格，並讓數量跟隨其商品選擇；尚未遷移的提交流程仍可處理原有單一選擇。
- [x] 舊草稿可經相容讀取繼續使用，不要求清空或重新輸入已有需求。
- [x] 首次開頁的既有預設選項行為保持可用；此票驗收有效選擇的保存，更新後失效的處理由 05 完成。
- [x] 訂製需求繼續保留自由描述、尺寸、附件及原商品資料。
- [x] 回歸測試涵蓋「選擇 → 有效刷新 → 草稿 → 登入還原」，並透過實際商品選擇畫面驗證。
