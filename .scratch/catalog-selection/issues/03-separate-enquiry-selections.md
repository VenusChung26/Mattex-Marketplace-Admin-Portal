# 03: 詢價按不同商品選擇分行

**What to build:** 買家就同款商品詢問不同尺寸或規格時，各商品選擇有自己的明細及數量；由草稿編輯、提交詢價，到銷售查看及生成詢價文件，均保留相同需求。

**Blocked by:** 02：商品選擇完整保留到草稿。

**Status:** done

- [x] 同款商品先加入「80mm × 2件」，再加入「100mm × 3件」，草稿保留兩行，不合併成「100mm × 5件」。
- [x] 修改數量、移除或選取提交某一行時，不影響同款商品的另一個規格。
- [x] 同一商品與相同尺寸／規格再次加入，可累加該商品選擇的數量；不跨規格累加。
- [x] 詢價提交資料與伺服器保存明細包含各行的商品選擇、數量及提交時的商品描述；不只依靠瀏覽器副本。
- [x] 銷售查看詢價及新生成的詢價文件時，兩行的尺寸、規格與數量均與買家提交一致。
- [x] 舊單一選擇草稿及訂製詢價仍可使用；編號、時間與詢價狀態繼續由伺服器決定。
- [x] 回歸驗證兩種規格的增刪改、登入還原、實際提交資料及銷售／文件結果；提交失敗時保留草稿。
