# 04: 採購單按不同商品選擇分行

**What to build:** 買家即買同款現貨的不同尺寸或規格時，草稿、提交、伺服器計價、採購單及買家文件均按各商品選擇分行，銷售收到的需求與買家確認內容一致。

**Blocked by:** 02：商品選擇完整保留到草稿。

**Status:** done

- [x] 「80mm × 2件」及「100mm × 3件」可作為兩個商品選擇購買，不因商品相同而合併或錯誤拒絕。
- [x] 從草稿及即買入口提交時，伺服器收到各行選擇與數量；不只收到商品與總數量。
- [x] 各行售價、單位、最低購買量及可售狀態依伺服器認可的商品選擇判定，沿用既有計價及推廣規則。
- [x] 採購單保存各行提交時的選擇描述；銷售畫面、買家確認內容及新生成文件保持一致。
- [x] 單一選擇、舊草稿及原有現貨即買入口仍可完成購買；須詢價的商品繼續使用詢價流程。
- [x] 修改或移除某一商品選擇，不會連帶改動另一行的數量或金額。
- [x] 回歸驗證多行同款商品的提交、計價、保存及文件結果；錯誤或失敗時保留買家草稿。
