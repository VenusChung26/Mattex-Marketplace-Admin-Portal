# 05: 失效規格必須重選

**What to build:** 商品資料更新令已選尺寸或規格失效時，買家仍可保留其他有效資料，清楚知道哪部分需要重選；只有修正後才可提交詢價或採購單，伺服器亦核對選擇。

**Blocked by:** 01：買家商品目錄前後一致；02：商品選擇完整保留到草稿。

**Status:** done

- [x] 原選「80mm」在更新後不存在時，標示原選擇失效，不自動改選「100mm」或首個可用選項。
- [x] 尺寸或上游規格失效時，標示受影響的相依選項；無關且仍有效的規格、數量、聯絡及交付資料繼續保留。
- [x] 商品卡、列表、詳情頁、登入前後的待處理選擇及草稿均能呈現需要重選的狀態，並讓買家回到該商品選擇修正。
- [x] 詢價及即買採購單的真正提交路徑會按最新買家商品目錄核對，不能只靠畫面停用按鈕。
- [x] 伺服器收到不存在或不相容的標準商品選擇時拒絕建立記錄，讓買家得知受影響明細；草稿不被清空。
- [x] 首次開頁的既有預設選項，與買家已作選擇在更新後失效，是不同情境；前者仍可沿用原有行為。
- [x] 訂製詢價仍以自由需求完整性處理，不因不在標準商品選項內而被否決。
- [x] 回歸測試涵蓋有效刷新、選項消失、相依組合改動及繞過畫面的無效提交，修正後可正常提交。
