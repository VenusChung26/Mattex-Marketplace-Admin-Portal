# Triage labels

以下使用已確認的預設名稱。本地 Markdown tracker 將名稱記錄在各票的 `Status` 欄位。

| Canonical role | 本專案名稱 | 意義 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要評估或分流 |
| `needs-info` | `needs-info` | 仍缺必要資料 |
| `ready-for-agent` | `ready-for-agent` | 規格齊備，可由 agent 處理 |
| `ready-for-human` | `ready-for-human` | 需要人手處理 |
| `wontfix` | `wontfix` | 已決定不處理 |

實際能否開工仍須讀取 `Blocked by`。完成狀態及 tracker 操作見 [issue-tracker.md](issue-tracker.md)。
